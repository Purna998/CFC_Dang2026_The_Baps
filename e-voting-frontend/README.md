# E-Voting System - Frontend

Modern Next.js frontend for the E-Voting System.

## Quick Start

```bash
# Install
npm install

# Configure
cp .env.local.example .env.local

# Run
npm run dev
```

Open http://localhost:3000

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Axios

## Pages

- `/login` - Login
- `/dashboard` - Dashboard
- `/elections` - Elections management
- `/candidates` - Candidates management
- `/voters` - Voter management (Admin)
- `/vote` - Vote casting (Voter)
- `/verify` - Vote verification
- `/results` - Results
- `/profile` - Profile

## Backend

Make sure backend is running on http://127.0.0.1:8000
